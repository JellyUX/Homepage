JellyUX Homepage

General

Show JellyUX widgets on the home screen. Disable to revert to the native Jellyfin home screen. To turn JellyUX off, always use this switch, never Disable on the plugin in the Jellyfin dashboard: Jellyfin 10.11 then deletes the plugin at the next restart.

Modules

A disabled module is not loaded at all. Changes apply after a page reload.

API Keys

Required for Connected widgets that use The Movie Database. Leave empty if not needed. Accepted formats: 32-character hexadecimal key (v3), or v4 bearer token starting with "ey".
Invalid TMDb key format. Expected: 32 hexadecimal characters, a v4 bearer token, or leave empty.

Cache

How long a user's home screen layout is kept before it is rebuilt, counted from when it was built. Saving this page applies changes at once. Personalized picks are recomputed once a day and after a title is finished, not on this schedule.
How often TMDb data is refreshed. Increase to reduce external API calls; decrease for fresher content.
