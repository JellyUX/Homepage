# Top Rated in Library

**Category:** Admin

Displays the best community-rated titles of your library, highest rating first. Unrated titles are
left out. Not to be confused with the TMDb Top Rated Movies and Top Rated Shows sections, which list
TMDb's ranking and only show the titles you own: this one ranks your own library, without a TMDb key,
in one query.

This preset is added disabled; turn it on from the admin page.

## Parameters

In addition to the [common parameters](../../configuration.md#common-per-widget-parameters):

| Field | Description |
|---|---|
| Show | Movies and series (default for a new section), movies only, or series only. |
