# Recently Released

**Category:** Admin

Displays the latest releases of your library, newest release date first. Titles dated in the future
are left out. The section needs no TMDb key: it reads your library only, in one query.

This preset is added disabled; turn it on from the admin page. You can add several Recently Released
sections, for example one for movies and one for series.

## Parameters

In addition to the [common parameters](../../configuration.md#common-per-widget-parameters):

| Field | Description |
|---|---|
| Show | Movies and series (default for a new section), movies only, or series only. |
